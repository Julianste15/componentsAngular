# Componentes Angular ⚙️

> Colección de componentes reutilizables en Angular 20: cabecera, pie de página y un módulo CRUD de clientes con formulario.

**🇪🇸 Español:** Proyecto Angular que demuestra la creación y composición de **componentes standalone**: `Header`, `Footer` y un módulo de clientes (listado + formulario + servicio de datos). Buen punto de partida para ver la estructura de componentes, rutas y servicios en Angular en su versión más reciente.

**🇺🇸 English:** An Angular project showcasing standalone **component composition**: Header, Footer, and a clients CRUD module (list + form + data service). A good reference to see components, routes and services in the latest Angular version.

## ✨ Funcionalidades / Features

- Componentes reutilizables (Header, Footer)
- Módulo CRUD de clientes con formulario y servicio
- Standalone components y routing por archivo

## 🛠️ Tecnologías / Tech Stack

- Angular 20 · TypeScript · RxJS · HTML/CSS

## 🚀 Ejecución / Getting Started

```bash
npm install
ng serve        # http://localhost:4200
```
